<BentoShell id="tips" eyebrow="How to search" heading="Tips">

- Search by **name** (`abyssal whip`) or **item id** (`4151`).
- Toggle **Members / Free** to limit by world type.
- Filter by **Equipment**, **Food**, **Potions**, **Quest**, **Drops**, **Farming**,
  **Gathering**, **Teleport**, **Ammunition**, or **Prayer**.
- Deep link with `?q=`, `?tag=`, and `?members=` — for example `/osrs/?tag=potion&members=f2p`.
- Every row shows item id, GE limit, high alch, and base value at a glance.

</BentoShell>
