The base of the line and the only pet that spawns in the wild. Every owned pet starts here.

<Aside type="caution" title="One evolution, eighteen outcomes">
	Using an evolution item on a Shibe is **permanent and unrepeatable**. There are eighteen
	forms and each Shibe gets exactly one of them — to get a different form, raise another
	Shibe.
</Aside>
