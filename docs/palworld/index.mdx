				Palworld runs on Unreal Engine, so mods load through

				bake it into the server image so Lua and C++ mods are live at
				boot. Rough shape:
			</p>
			<ul class="pal-steps">
				<li>
					Drop UE4SS next to the server binary in
					<code>Pal/Binaries/Win64</code> — on the Linux dedicated
					build this is the Proton prefix path.
				</li>
				<li>
					Put each mod under <code>Mods/&lt;ModName&gt;/</code> and
					enable it in <code>Mods/mods.txt</code>.
				</li>
				<li>
					Lua entrypoint is <code>Scripts/main.lua</code>; iterate with
					the UE4SS live console and hot-reload.
				</li>
			</ul>
			<p class="bento-rulecard__desc pal-note">
				Note: Palworld dedicated on Linux runs under Proton — UE4SS loads
				through the prefix, and our image bakes that path so mods stay
				portable across the fleet.
			</p>
