# Secret names GitHub Actions can resolve for this repository, plus the ones a

# A workflow that references `secrets.X` where X exists in neither list fails
# `node tools/ci/check-workflow-secrets.mjs`. That check exists because the
# failure mode has no other symptom: a missing secret resolves to an empty
# string, and the step that consumes it reports its own confusing error far from
# the cause. `MY_GITHUB_TOKEN` broke every docker publish with "Password
# required", and `TRIGGER_PAT` broke every post-publish with "Input required and
# not supplied: token". Neither name had ever existed.
#
