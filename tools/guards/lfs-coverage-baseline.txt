# Tracked binaries under a game's LFS prefix that carry no LFS filter.
#
# Two kinds of entry, and they are not the same thing:
#
#   meant to stay plain   vendored third-party payloads (Unity's NuGet DLLs
#                         and their package icons, gdUnit4's bundled UI art),
#                         tauri bundler icons, and playwright screenshot
#                         baselines. These are build inputs read before any
#                         LFS hydrate runs; a pointer stub here fails the
#                         build, not the asset.
#
#   real gaps, unmigrated the rule for the game covers a narrower set of
#                         extensions or a narrower root than the game
#                         actually uses: arpg has .obj/.jpg models outside
#                         its png/webp rule, herbmail keeps shader plates
#                         under src/ rather than public/, rareicon's texture
#                         rule pins Textures/Environment while the atlases
#                         sit in StreamingAssets and Resources/Ocean, and
#                         isometric's art is a level deeper than the
#                         apps/arcade/*/assets glob reaches.
#
# Migrating the second kind is not a .gitattributes edit alone: renormalizing
# writes pointers, and the blobs have to reach each game's Forgejo endpoint
# first or every hydrate 404s. Do it per game, with the push, then drop the
# lines here -- a baseline entry that stops matching fails the guard, so the
# file cannot outlive the gap.
#
# Regenerate after an intentional change: moon run guards:sync-lfs-baseline
